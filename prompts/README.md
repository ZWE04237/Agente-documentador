# Prompts

Aquí van los **prompts específicos reutilizables** para cada paso del roadmap.

## Uso
1. Abre `ROADMAP_AGENTE_DOCUMENTADOR_OPENCODE_BIGPICKLE.md`
2. Copia el prompt específico del paso que corresponda
3. Pégalo directamente en OpenCode con Big Pickle
4. Ejecuta siguiendo estrictamente `PROMPT_MAESTRO_AGENTE_DOCUMENTADOR_OPENCODE.md`

## Plantillas
- `PROMPT_TEMPLATE_STEP.md` - Plantilla base para crear nuevos prompts de paso
